# 📌 13주차 - 우선순위 큐(Priority Queue)와 힙 구조

이번 주차에서는 **우선순위 큐(Priority Queue)**의 개념과 **힙(Heap)** 자료구조를 이용한 구현을 실습했습니다. 
우선순위 큐는 작업 스케줄링, 최단 경로 탐색 등 다양한 알고리즘에서 필수적으로 사용되는 자료구조입니다.

---

## 🗂️ 파일 목록 및 설명

| 파일명 | 설명 |
|--------|------|
| `basic_priority_queue.py` | 기본적인 우선순위 큐 개념을 설명하고 구현 예시를 포함한 코드입니다. |
| `heapq_priority_queue.py` | `heapq` 모듈을 활용하여 최소 힙을 구현하고, 우선순위 큐로 동작하는 예시를 포함합니다. |
| `priority_Queue.py` | 클래스를 이용해 우선순위 큐를 직접 구현한 코드로, 삽입과 삭제 연산을 중심으로 구성되어 있습니다. |

## 📌 학습 포인트

- 우선순위 큐의 동작 원리 및 용도 이해
- Python의 `heapq` 라이브러리 사용법
- 클래스 기반의 우선순위 큐 구현 실습
- `heapq.heappush()`, `heapq.heappop()` 함수 사용
