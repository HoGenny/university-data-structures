# 📚 자료구조 (Python) — 2025년 1학기

가천대학교 **자료구조** 과목에서 학습한 내용을 주차별로 정리한 저장소입니다.  
각 주차별 핵심 개념을 바탕으로 **Python 구현 코드 + 간단한 설명/주석**을 포함합니다.

> ✅ 목표: “강의 복습 + 코딩테스트에 바로 쓰이는 구현 감각”을 동시에 챙기기

---

## 🎯 Repository Goals

- 강의에서 다룬 자료구조/알고리즘을 **직접 구현하며 이해**
- 핵심 패턴(정렬/탐색/재귀/그래프)을 **주차 단위로 빠르게 복습**
- 코딩테스트에서 자주 쓰이는 풀이 아이디어를 **정리 + 코드로 축적**

---

## 🗂️ Structure

```
.
├── src/
│   ├── week01/
│   │   ├── atoi.py
│   │   ├── find_max_index.py
│   │   ├── ...
│   │   └── README.md
│   ├── week02/
│   ├── ...
│   └── week14/
└── README.md
```

- `src/weekXX/README.md`: 해당 주차 핵심 개념 + 실행 방법 + 예제 (8주차는 중간고사라 폴더 없음)
- 파일명은 동작/문제를 바로 떠올릴 수 있게 간단히

## 🚀 Quick Start

### Run (기본 실행)
```bash
python src/week01/atoi.py
```

### Python Version
- Python **3.8+** 권장

> 주차별 코드가 함수/모듈 형태라면 `python -m` 구조로 바꾸는 것도 좋아요.
