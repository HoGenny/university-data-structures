# 📘 1주차 - 기본 알고리즘 연습

이 폴더는 가천대학교 자료구조 수업 1주차의 학습 내용을 정리한 것입니다.  
기본적인 리스트 처리, 최대값 찾기, 문자열 역순 처리, 문자열-정수 변환 등을 Python으로 구현해 보았습니다.

---

## 🗂️ 파일 목록 및 설명

| 파일명 | 설명 |
|--------|------|
| `find_max_index.py` | 리스트에서 최대값의 인덱스를 수동으로 찾아 출력합니다. |
| `max_index_builtin.py` | 내장 함수 `max()`와 `index()`를 활용하여 최대값의 인덱스를 찾습니다. |
| `reverse_slice.py` | 리스트를 `[::-1]` 슬라이싱으로 역순으로 만듭니다. |
| `reverse_methods.py` | 리스트를 `.reverse()` 메서드로 역순 처리하고 출력합니다. |
| `reverse_sublist.py` | 리스트의 일부를 역순으로 만들고 전체 리스트에 반영합니다. |
| `atoi.py` | 문자열을 정수로 변환하는 `atoi` 기능을 직접 구현합니다. |

---

## 📌 학습 포인트

- 최대값을 **수동 탐색**과 **내장 함수**를 통해 비교해 보기
- 리스트를 역순으로 만드는 다양한 방법 실습
- 문자열을 숫자로 변환하는 기본 로직 구현 (`atoi`)
- Python의 리스트와 문자열 조작법에 익숙해지기
